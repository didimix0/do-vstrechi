# Проверки исходного кода

Полный локальный пакет проекта, включающий закрытые учебные данные, ранее прошёл 290 автоматических тестов без обращения к реальному API. Этот результат не следует выдавать за результат запуска одной публичной копии без данных.

В публичной версии предусмотрен отдельный запуск независимых проверок конфигурации и обработки аудио, а также проверка синтаксиса и `--help`. Тесты происхождения банковских материалов требуют отдельного разрешённого набора.

Проверки программы не являются измерением точности модели, пользовательским исследованием или банковским пилотом.
