# Подключение учебных данных

В публичной копии нет банковских документов и производных от них материалов. Описание необходимых каталогов находится в `data/README.md`, проверка формата — в `src/do_vstrechi/data.py` и `contracts.py`.

Исходный проект использует отдельные JSON-файлы для состояния разговора, критериев, продукта и примеров. Для каждой попытки фиксируется версия этих материалов. Это не обучение весов LLM и не автоматическое чтение всех тарифов из интернета.

Набор подключается локально с разрешения его владельца. До запуска проверьте согласованность имён файлов и идентификаторов, ссылки на источники, сроки действия и ограничения применимости. Не добавляйте документы и извлечённые сведения в публичный Git без отдельного разрешения.

Тесты, проверяющие происхождение цитат и контрольные суммы исходников, требуют разрешённого локального пакета. В открытой версии можно отдельно выполнить проверки независимых компонентов.
