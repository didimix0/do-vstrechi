# Конфигурация и доступ

Секреты находятся только в локальном `.env`; пустой пример — `.env.example`. Ключ провайдера остаётся на сервере и не передаётся браузеру.

Учебные данные подключаются отдельно, как описано в `data/README.md`. Временные записи, модели, базы попыток и файлы проверки хранятся в исключённой из Git папке `var/`.

Полноценный запуск требует отдельного набора данных и собственного доступа к GigaChat. Для доверенного корневого сертификата задаётся `GIGACHAT_CA_BUNDLE`; сертификаты в публичной копии отсутствуют.

Основной локальный сервер слушает `127.0.0.1:8766`. Публикация кода не включает временный доступ или HTTPS-туннель. Их адреса, коды и история в репозиторий не попадают.

Для реальных сотрудников отдельно согласуются авторизация, хранение, удаление, аудит и способ подключения LLM. Эта копия предназначена для изучения реализации учебного прототипа.
