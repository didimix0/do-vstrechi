# До встречи

Голосовой ИИ-тренажёр для выездных представителей банка. Учебный проект первого спринта Академии Финтеха.

Представитель отрабатывает звонок клиенту, который заказал обычную дебетовую карту ВТБ, но перед встречей передумал её получать. После разговора доступны оценка, цитаты из ответов и рекомендации.

## Что работает

- Браузерный интерфейс, свободный ввод текста, история попыток и подробный разбор.
- Три характера клиента: спокойный, спешащий и недоверчивый.
- Анализ действий и ответы клиента через GigaChat-2-Pro; отдельный запрос для оценки.
- Программный контроль этапов, памяти вопросов, окончательного отказа и завершения звонка.
- 10 критериев, рейтинг 0–100 и исключение неприменимых шагов из расчёта.
- Голосовой ввод через локальный Vosk; текст можно проверить и исправить перед отправкой.
- Озвучивание ответа локальным русским голосом устройства, если он доступен в браузере.
- 18 базовых фактов о карте, версии источников, 30 рабочих примеров речи и 10 отдельных контрольных ситуаций.

Три характера относятся к одному сценарию звонка. Личная встреча, кросс-продажи, учебные уровни и банковские интеграции относятся к следующим этапам. Дообучения весов LLM нет: используются инструкции, примеры, сведения о продукте и состояние разговора.

## Быстрый запуск

Нужен Python 3.11 или новее. Команды выполняются в корне этого репозитория. Для текстовой демонстрации сторонние Python-пакеты не нужны.

```bash
git clone https://github.com/didimix0/do-vstrechi.git
cd do-vstrechi
python run.py --check
python run.py --serve --open-browser
```

Основной локальный адрес: **http://127.0.0.1:8766**. Сервер должен оставаться запущенным. На Windows также можно открыть `start.cmd` и выбрать браузерный тренажёр.

Без API-ключа доступна демонстрация с готовыми репликами. Она показывает учебный процесс; это не работа нейросети. Для свободного разговора с GigaChat нужен собственный доступ к API.

## Подключение GigaChat

Ключ получают в кабинете разработчика провайдера. Не вставляйте его в исходники, GitHub, issues или сообщения.

```bash
python run.py --configure
python run.py --check-api
python run.py --serve --open-browser
```

Настройка сохраняется локально в `.env`, который исключён из Git. Безопасный пример пустых настроек находится в `.env.example`. В нём указаны `GIGACHAT_SCOPE=GIGACHAT_API_PERS` и `GIGACHAT_MODEL=GigaChat-2-Pro`; для корпоративного доступа параметры задаются по условиям провайдера.

Если необходимо доверие отдельному корневому сертификату, укажите путь к доверенному PEM в `GIGACHAT_CA_BUNDLE`. В репозитории есть публичный корневой сертификат, использованный в прототипе. Проверка TLS должна оставаться включённой; устанавливать сертификат в системное хранилище через приложение не требуется.

Проверка API и свободный режим расходуют токены. Действующие тарифы и лимиты определяются выбранным аккаунтом провайдера. Инструкции: https://developers.sber.ru/docs/ru/gigachat/api/overview

## Голосовой ввод

Установите зависимости и скачайте открытую русскую модель:

```bash
python -m pip install --target var/voice-runtime -r requirements-voice.txt
python scripts/install_voice.py
```

Затем перезапустите сервер. Нажмите «Записать реплику», остановите запись и проверьте распознанный текст перед отправкой. Клавиатурный ввод доступен независимо от установки Vosk. Записи, скачанные модели и зависимости хранятся в `var/` и не публикуются.

Голосовой режим работает по очереди реплик. Это не телефонное соединение и не одновременный разговор с перебиваниями. Доступ к микрофону в браузере требует разрешения пользователя; для удалённого подключения требуется корректно настроенный HTTPS.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Основной набор не требует реального API-ключа. Сетевые проверки в `scripts/` выполняются отдельно; варианты с `--live` обращаются к провайдеру и расходуют токены. Количество автоматических тестов характеризует проверки программы, а не точность модели и не число пользователей.

## Структура

```text
src/do_vstrechi/  сервер, состояние разговора, модель, оценка, хранение и голос
web/              интерфейс HTML/CSS/JavaScript без сборки
data/             сценарии, критерии, условия карты и источники
prompts/          инструкции анализатора, клиента и оценщика с архивами версий
tests/            автоматические проверки и учебные фикстуры
scripts/          настройка голоса и отдельные технические проверки
docs/             актуальное описание устройства и данных
var/              локальные данные, создаётся при работе и исключена из Git
```

Подробнее: [архитектура](docs/architecture.md), [учебные данные и источники](docs/data.md), [конфигурация и доступ](docs/configuration.md).

## Учебный контекст

Клиенты, имена, адреса и ситуации в упражнениях вымышлены. Условия продуктов закреплены в версии материалов октября 2026 года, с ограничениями применимости. Они предназначены для воспроизводимости упражнения и не заменяют действующие тарифы банка.

В репозиторий не включены рабочий API-ключ, базы учебных сессий, записи голоса, журналы временного доступа, результаты опроса сотрудников и частные технические выгрузки. Публичный репозиторий содержит исходники и материалы, необходимые для локального запуска и проверки.
