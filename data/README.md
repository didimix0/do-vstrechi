# Локальные учебные данные

Исходные банковские документы и извлечённые из них сведения не включены в публичный репозиторий по решению команды.

Для полного запуска тренажёра необходим локальный согласованный набор:

- `scenarios/` — текущий сценарий звонка и архивы для исторических фикстур;
- `rubrics/` — критерии оценки и применимость шагов;
- `products/` — версионированный паспорт продукта и отдельный каталог предложений;
- `dialogue_examples/` — 30 рабочих примеров и 10 контрольных ситуаций;
- `sources/` — источники, цитаты и манифесты для проверок происхождения.

Подключите эти каталоги локально из разрешённого пакета данных вашей команды. Их нельзя добавлять в Git автоматически. Исходный формат проверяется функцией `validate_bundle` в `src/do_vstrechi/data.py`. Загрузчик ожидает существующие имена файлов, указанные в этом модуле.

После подключения:

```bash
python run.py --check
python -m unittest discover -s tests -v
python run.py --serve --open-browser
```

Воспроизведение банковских условий и полного сценария из одной публичной копии без локальных материалов не предусмотрено. Сам код анализатора, состояния, оценщика, сервера и интерфейса опубликован.
