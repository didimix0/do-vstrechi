# Проверка полного набора

28 октября 2026 года отдельная копия проекта проверяется без рабочего `.env` и без обращений к реальному GigaChat API:

```bash
python run.py --check
python run.py --demo
python -m unittest discover -s tests
```

Публичная версия содержит сценарии, критерии и зафиксированные источники, поэтому полный набор проверок не требует отдельной передачи банковских документов. Для тестов не нужны скачанная модель Vosk и действующий API-ключ.

Автоматические тесты проверяют программу и учебные фикстуры. Их число не является измерением точности модели, результатом опроса или пилотом с сотрудниками банка.
