# До встречи

Исходный код голосового ИИ-тренажёра для выездных представителей банка. Учебный проект первого спринта Академии Финтеха, подготовленный командой студентов ЭФ МГУ.

**В этой публичной версии опубликован только код. Банковские документы, тарифы, скриншоты и извлечённые сведения не включены.** Для полноценного запуска нужно отдельно подключить согласованный локальный набор учебных данных. См. [data/README.md](data/README.md).

## Что реализовано в прототипе

- Браузерный интерфейс, свободный ввод текста, история попыток и подробный разбор.
- Звонок перед получением карты и три характера клиента: спокойный, спешащий, недоверчивый.
- Анализ действий и формулирование ответа через GigaChat-2-Pro; отдельный запрос для оценки.
- Программный контроль этапов, памяти вопросов, повторений, окончательного отказа и завершения.
- 10 критериев, рейтинг 0–100 и исключение неприменимых шагов из расчёта.
- Локальный голосовой ввод Vosk с редактированием распознанного текста перед отправкой.
- Озвучивание ответа локальным голосом устройства, если он доступен в браузере.

Перечисленные функции работают в прототипе с локальными материалами команды. Публичная копия содержит их реализацию, но не банковскую базу знаний. Личная встреча, кросс-продажи, учебные уровни и банковские интеграции относятся к дальнейшим этапам. Дообучение весов LLM не проводилось.

## Получение кода и проверка без банковских данных

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/didimix0/do-vstrechi.git
cd do-vstrechi
python run.py --help
python -m compileall -q src scripts tests
```

Это проверяет наличие исходников, синтаксис и интерфейс команд. Полный учебный сценарий требует отдельного набора данных; успешный `--help` не является запуском диалога.

## Полный локальный запуск

1. Подключите в `data/` разрешённые сценарии, критерии, продукты, примеры и источники по [описанию набора](data/README.md).
2. Выполните проверку материалов и запуск:

```bash
python run.py --check
python run.py --serve --open-browser
```

Основной адрес: **http://127.0.0.1:8766**. Сервер должен оставаться запущенным. На Windows также можно открыть `start.cmd` и выбрать браузерный тренажёр.

Демонстрация с готовыми репликами не требует API-ключа, но также использует локальные файлы сценария. Свободный диалог требует доступа к GigaChat.

## Подключение GigaChat

```bash
python run.py --configure
python run.py --check-api
```

Настройка сохраняется локально в `.env`, исключённом из Git. Пример пустых настроек — `.env.example`. Ключ провайдера остаётся на сервере и не публикуется. В примере выбрана модель `GigaChat-2-Pro` и персональный scope; параметры корпоративного доступа задаются по условиям провайдера.

Если нужен отдельный доверенный корневой сертификат, укажите путь к полученному из доверенного источника PEM в `GIGACHAT_CA_BUNDLE`. Сертификаты не включены в этот репозиторий. Не отключайте проверку TLS. Документация провайдера: https://developers.sber.ru/docs/ru/gigachat/api/overview

Проверка API, сетевые скрипты с `--live` и свободный диалог расходуют токены.

## Голосовой ввод

```bash
python -m pip install --target var/voice-runtime -r requirements-voice.txt
python scripts/install_voice.py
```

Скрипт скачивает открытую русскую модель Vosk. Затем перезапустите сервер. После записи проверьте текст перед отправкой. Голос работает по очереди реплик; телефонное соединение и одновременное перебивание не реализованы.

Модели, зависимости, записи и базы попыток хранятся в `var/` и исключены из Git. Для локального браузера нужен доступ к микрофону, для удалённого подключения — настроенный HTTPS.

## Тесты

Полный набор выполняется после подключения локальных учебных данных:

```bash
python -m unittest discover -s tests -v
```

Без банковских данных можно проверить отдельные независимые компоненты:

```bash
python -m unittest discover -s tests -p test_public_components.py -v
```

Результаты проверки публичной копии и полного локального пакета разделены в [docs/verification.md](docs/verification.md).

## Структура

```text
src/do_vstrechi/  сервер, состояние диалога, модель, оценка, хранение и голос
web/              интерфейс HTML/CSS/JavaScript без сборки
prompts/          инструкции ролей и архивы их версий
tests/            проверки кода и исторические учебные фикстуры
scripts/          настройка голоса и технические проверки
docs/             устройство, конфигурация и правила подключения данных
data/README.md    описание отдельного локального набора
var/              локальные файлы, создаётся при работе и исключена из Git
```

Подробнее: [архитектура](docs/architecture.md), [данные](docs/data.md), [конфигурация](docs/configuration.md).

## Разделение доступа

В публичной копии отсутствуют API-ключ, рабочий `.env`, история разговоров, голосовые записи, результаты опроса, банковские документы и их извлечённые данные. Публикация исходников не запускает сайт и не открывает доступ к локальному компьютеру.

Материалы Taskmaster и ABCD использовались при подготовке локальных вымышленных учебных примеров; такие данные и их исходные лицензии хранятся в отдельном пакете и в этот репозиторий не включены. Зависимости Vosk и выбранная модель имеют собственные лицензии, указанные разработчиками.

Проект не является официальным продуктом ВТБ. Автоматические проверки программы не являются доказательством точности LLM или роста конверсии продаж.
