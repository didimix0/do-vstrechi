# Конфигурация и доступ

Рабочие секреты находятся только в локальном `.env`; пример пустых настроек — `.env.example`. Ключ провайдера остаётся на сервере и не должен передаваться браузеру.

Новые учебные попытки и история сохраняются в `var/`. В эту же папку устанавливаются Vosk, русская модель, временные записи и результаты сетевых проверок. Она полностью исключена из Git.

Публикация исходного кода не запускает сайт и не даёт посторонним доступ к локальному API-ключу. Для свободного диалога после клонирования нужен собственный настроенный доступ к GigaChat.

Основной сервер слушает `127.0.0.1:8766`. Временный режим проверки командой включается отдельно и требует серверной настройки и HTTPS-туннеля. Его адреса, коды и базы отсутствуют в репозитории. Повторно публиковать временный доступ для чтения кода не требуется.

Развёртывание для реальных сотрудников требует отдельной настройки авторизации, хранения, журналирования, согласованных сроков удаления и допустимого способа подключения LLM. Текущий учебный прототип не выдаёт себя за промышленную банковскую систему.
